# Creative Tuning Profiles

Valleytainment Visual Brain exposes operator-facing creature personalities for rapid A/B tuning on a real song and display.

| Profile | Character | Best use |
| --- | --- | --- |
| `BALANCED` | neutral festival baseline | default full-show behavior |
| `WET` | glossy, viscous, saliva/slime-forward | melodic, psychedelic, liquid sections |
| `CREEPY` | slower, watchful, restrained, uncanny | intros, breakdowns, dark passages |
| `AGGRESSIVE` | punchy, reactive, wider motion and shock response | builds, bass music, hard drops |
| `UNHINGED` | maximum safe procedural chaos | peak drops and short hero moments |

## Calibration loop

1. Launch with `vbrain launch`.
2. Use one representative reference track and keep playback volume fixed.
3. Replay the same 20–30 second section while switching only the creature profile.
4. Judge readability first: `VALLEYTAINMENT` must remain legible at all times.
5. Judge timing second: kick/drop motion should feel attached to the music, not delayed.
6. Judge life third: the creature should still breathe and feel sentient during quiet moments.
7. Use `UNHINGED` as a short-duration peak state, not the permanent default.

The profile system changes procedural behavior only. It never redraws or mutates the canonical Valleytainment logo asset.
